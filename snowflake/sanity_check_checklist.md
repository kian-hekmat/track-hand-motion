## 0. How to look

- Open the overlay clip `evidence/vidN_overlay.mp4` in QuickTime (or VLC). The top-left label reads `vidN f=<frame> t=<seconds>s`; **use that `t=`, not the player's clock** (the video has variable frame rate).
- Step one frame at a time with the left/right arrow keys. A clip shows the hand skeleton, not the phase names; the phases are in the tables below.
- Boundary rules (same ones used for the hand labelling): REST>REACH the hand leaves A; REACH>GRASP fingers start closing; GRASP>HOLD the lift ends and the object stops; HOLD>RELEASE the object touches the table and fingers start opening; RELEASE>RETRACT the hand starts back toward A; RETRACT>REST the hand is on A and stopped.
- **Tolerance: a boundary within 0.1 s of the listed time counts as correct** (the project's scoring tolerance).
- For the detected-vs-labelled picture, open `evidence/phase2_v2/vidN_segmentation.png` (top strip = hand-labelled, second strip = detected).
- What a disagreement means: the Snowflake numbers are already proven to equal the pipeline's events (see `snowflake/README.md`). This check asks whether the **events themselves** match what happened on camera. A mismatch is therefore a finding about the segmenter or the labels, not about Snowflake. Mismatches that match the *Known explanation* column in section C2, or the limits listed in section E, are expected.
